# HMSE UNIPI - Himpunan Mahasiswa Software Engineering

Selamat datang di repositori resmi **Himpunan Mahasiswa Software Engineering (HMSE)** Universitas Insan Pembangunan Indonesia (UNIPI). Repositori ini berfungsi sebagai pusat informasi, dokumentasi kegiatan, serta ruang kolaborasi proyek perangkat lunak bagi seluruh mahasiswa Software Engineering UNIPI.

---

## 📌 Tentang HMSE UNIPI

**HMSE UNIPI** adalah organisasi kemahasiswaan tingkat program studi yang diresmikan pada **07 Januari 2024**. Organisasi ini menjadi wadah bagi mahasiswa untuk mengembangkan potensi akademik dan non-akademik, khususnya di bidang rekayasa perangkat lunak, pemrograman, dan teknologi informasi.

### 🚀 Visi & Misi

- **Visi:** Mewujudkan ekosistem pengembangan perangkat lunak yang inovatif, kolaboratif dan berintegritas bagi mahasiswa software engineering. 
- **Misi:**
  1.  Mewujudkan tali silaturahmi mahasiswa/i jurusan software engineering.
  2.  Mengembangkan program pembelajaran, pelatihan dan proyek rekayasa perangkat lunak yang inovatif, berkualitas dan berkelanjutan.
  3.  Menjadi pusat pengembangan teknologi dan kreatifitas mahasiswa software engineering.
  4.  Menjalankan kegiatan kemasyarakatan yang bermanfaat.
  5.  Menjalin hubungan yang baik dengan seluruh Organisasi Kemahasiswaan di Indonesia.

## 🛠️ Fokus Teknologi & Keilmuan

Kami aktif mengeksplorasi, mempelajari, dan mengembangkan proyek menggunakan teknologi berikut:

- **Web Development:** HTML5, CSS3, JavaScript, PHP
- **Database & Backend:** SQL, RESTful API
- **Mobile Development:** Flutter, Dart
- **Tools & Platform:** Git, GitHub, Docker

---

## 📅 Program Kerja & Kegiatan

1.  **Bootcamp & Workshop:** Pelatihan intensif teknologi terkini (seperti _Mobile App Development_ menggunakan Flutter).
2.  **Study Club (Belajar Bersama):** Sesi rutin mingguan membahas dasar-dasar pemrograman dan pemecahan masalah algoritma.
3.  **Seminar Nasional:** Diskusi interaktif bersama praktisi industri mengenai tren karier di bidang IT.
4.  **HMSE Open House & Olahraga:** Kegiatan keakraban untuk mempererat tali persaudaraan antar mahasiswa.

## 🤝 Berkontribusi

Kami sangat terbuka bagi seluruh mahasiswa UNIPI yang ingin berkontribusi dalam proyek rekayasa perangkat lunak bersama kami!

1.  Fork repositori ini.
2.  Buat _branch_ fitur baru Anda (`git checkout -b fitur/FiturKeren`).
3.  Commit perubahan Anda (`git commit -m 'Menambahkan fitur keren'`).
4.  Push ke _branch_ tersebut (`git push origin fitur/FiturKeren`).
5.  Buka _Pull Request_.
